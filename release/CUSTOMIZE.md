# 나에게 맞게 바꾸기

두 단계가 있어요. **코드 없이 설정만** 바꾸거나, **내 Claude Code에게 부탁해서** 기능 자체를 고칠 수 있어요.

---

## 1단계: 설정만 바꾸기 (코드 없이)

옵시디언 → 설정 → **Claude Sidebar**

| 설정 | 기본값 | 이럴 때 바꿔요 |
|---|---|---|
| 모델 | Sonnet | 더 빠르게: Haiku / 더 똑똑하게: Opus (사용량을 많이 씀) |
| 생각 깊이 | 낮음 | 대답이 얕다 싶으면 보통이나 높음 (느려짐) |
| 대화 저장 폴더 | `Claude` | 💾로 저장한 대화가 들어갈 곳 |
| 매일 아침 브리핑 · 시각 | 꺼짐 · 08:30 | 출근이나 등교 시간에 맞추기 |
| 프로젝트 찾을 곳 | 바탕화면 등 | 코드 폴더가 `D:\dev` 같은 다른 곳에 있을 때 |
| 프로젝트 노트 폴더 | `프로젝트` | 볼트의 폴더 구조에 맞추기 |
| 받은자료 · 자료 폴더 | `받은자료` · `자료` | 이미 쓰는 Inbox, 자료실 폴더가 있을 때 |

---

## 2단계: 내 Claude로 기능 고치기

zip 안의 **`source` 폴더**가 이 플러그인의 전체 코드예요. 그 안의 `CLAUDE.md` 에 구조와 규칙이 적혀 있어서, 내 Claude Code가 폴더를 열면 알아서 읽고 고쳐 줘요. **코드를 몰라도 돼요.** 원하는 걸 말로 부탁하면 돼요.

### 준비 (처음 한 번)

1. **Node.js**와 **Claude Code**가 깔려 있어야 해요 (`START-HERE.md`의 준비물 참고).
2. 고칠 코드를 둘 곳으로 `source` 폴더를 옮겨요 (예: `문서\claude-sidebar`). 이름은 아무거나 괜찮아요.
3. 그 폴더에서 Claude Code를 열어요.
   - **Windows:** 탐색기로 폴더를 열고 → 위쪽 주소창에 `cmd` 입력 후 Enter → 뜬 창에 `claude`
   - **Mac:** 터미널에서 `cd ` (한 칸 띄우고) 폴더를 끌어다 놓고 Enter → `claude`
4. Claude에게 첫 부탁을 해요.
   > 이 플러그인을 빌드해서 내 옵시디언 볼트에 설치해줘

   Claude가 `npm install` → 빌드 → 볼트에 설치까지 해 줘요. 끝나면 옵시디언을 껐다 켜세요.

### 이렇게 부탁하면 돼요 (복사해서 쓰세요)

**아침 브리핑**
> 아침 브리핑에서 오늘 할 일을 3개로 줄이고, 맨 위에 "이번 주 목표" 칸을 추가해줘. 이번 주 목표는 `프로젝트/이번주.md` 에서 읽어와.

> 브리핑할 때 데일리 노트 말고 `Daily/YYYY-MM-DD.md` 형식으로 저장되게 해줘.

> 저녁 9시에 "오늘 회고" 브리핑도 한 번 더 해줘. 오늘 커밋과 데일리 노트를 보고 잘한 것 / 내일 이어갈 것을 써줘.

**자료 정리**
> 자료를 분류할 때 내가 정한 분류(공부, 업무, 취미, 돈, 기타)만 쓰게 해줘.

> 자료 정리 노트 맨 아래에 "내 생각:" 빈칸을 넣어줘.

> 유튜브 링크를 넣으면 제목이랑 설명을 읽어서 정리해줘.

**대화·다듬기**
> 대답할 때 존댓말로, 그리고 항상 마지막에 다음 행동 하나를 제안하게 해줘.

> 다듬기 버튼을 누르면 영어 노트는 영어로, 한국어 노트는 한국어로 다듬게 해줘.

> 사이드바 입력창 위에 "요약", "할 일 뽑기" 빠른 버튼 두 개를 추가해줘.

**모양**
> 사이드바 색을 파란색 계열로 바꾸고, 말풍선 모서리를 더 둥글게 해줘.

### 고친 뒤에는

Claude가 테스트(`npm test`)를 돌리고 볼트에 다시 설치(`npm run install-vault`)해 줘요. **옵시디언을 껐다 켜면** 바뀐 게 보여요.
마음에 안 들면 이렇게 말하면 돼요.
> 방금 바꾼 거 되돌려줘

### 망가지면

zip의 `install-windows.bat` (Mac은 `install-mac.command`)를 다시 실행하면 처음 버전으로 돌아가요. 노트와 대화 기록은 그대로예요.

**버전 기록을 남기면 더 안전해요.** 처음 한 번 Claude에게 이렇게 부탁해 두세요.
> 이 폴더를 git으로 관리해줘. 앞으로 고칠 때마다 커밋해줘.

그러면 언제든 "어제 버전으로 돌려줘"가 돼요.

## 어디를 고치면 뭐가 바뀌나요? (궁금한 사람만)

| 파일 | 내용 |
|---|---|
| `src/prompts.ts` | 대화, 다듬기, 대화 저장 때 Claude에게 주는 지시문 |
| `src/assistant/prompts.ts` | 아침 브리핑과 프로젝트 체크리스트 초안 지시문 |
| `src/assistant/inbox.ts` | 자료 정리 지시문, 분류 규칙, 읽을 수 있는 파일 종류 |
| `src/assistant/morning.ts` | 아침 브리핑 순서 (수집 → 프로젝트 노트 → 현황표 → 할 일) |
| `src/assistant/collect.ts` | GitHub과 내 PC 폴더에서 프로젝트를 찾는 방법 |
| `src/view.ts` | 사이드바 화면과 버튼 |
| `src/main.ts` | 설정 화면, 명령어 |
| `styles.css` | 색, 크기, 움직임 |
