# Claude Sidebar: 옵시디언 개인 비서

옵시디언 오른쪽에 붙는 Claude 비서예요. **내 Claude Code 구독**으로 돌아가서 API 키나 추가 요금이 없어요.

| | 하는 일 |
|---|---|
| 💬 물어보기 | 내 노트와 프로젝트(GitHub, 내 PC의 폴더)를 찾아 답하고, 근거 노트를 링크로 달아 줘요 |
| 📅 브리핑 | 아침엔 **오늘 할 일**, 점심엔 **오후 점검**, 저녁엔 **오늘 회고**를 데일리 노트에 쓰고 알림을 띄워요. 정한 시각에 자동으로도 돼요 |
| 📌 일정 · 🔁 루틴 | "금요일 3시 치과", "매일 7시 영어 단어"처럼 말하면 넣어 두고, 그날 할 일에 붙이고, 15분 전에 알려요. 루틴은 연속 기록(🔥)도 세요 |
| 📆 애플 캘린더 (맥) | 캘린더 일정을 할 일과 브리핑에 쓰고, 말한 일정을 캘린더에 넣어요 |
| 📥 자료 정리 | 파일(PDF, 이미지, 워드, 파워포인트, 한글 hwpx, HTML)이나 글·링크, 폴더째로 넣으면 요약해서 분류 폴더에 저장해요 |
| ✨ 다듬기 | 열린 노트의 맞춤법과 구조를 정리해요 (내용은 그대로) |
| 💾 저장 | 지금까지의 대화를 노트로 정리해요 |

**나에게 맞게 바꾸고 싶으면 → `CUSTOMIZE.md`**

---

## 1. 준비물

| | Windows | Mac |
|---|---|---|
| **옵시디언** | https://obsidian.md | 같음 |
| **Claude Code** (필수, Pro 이상 구독) | PowerShell에서 `irm https://claude.ai/install.ps1 \| iex` | 터미널에서 `curl -fsSL https://claude.ai/install.sh \| bash` |
| **Git** (윈도우 필수) | `winget install --id Git.Git` | 보통 이미 있음 |
| **Node.js** (자동 비서에 필요) | `winget install OpenJS.NodeJS.LTS` | https://nodejs.org |
| **GitHub CLI** (선택) | `winget install --id GitHub.cli` | `brew install gh` |

설치한 뒤에 할 일:
- **Claude Code 로그인:** 터미널(PowerShell)에서 `claude` 를 **한 번 실행해서 로그인**하세요.
- **GitHub 로그인(선택):** GitHub CLI를 깔았다면 `gh auth login` 으로 로그인하세요. 그러면 내 GitHub 저장소까지 챙겨요.

## 2. 설치

### Windows

1. zip 파일을 우클릭 → **압축 풀기**.
2. 푼 폴더에서 **`install-windows.bat`** 을 더블클릭.
   - "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**.
   - 볼트가 여러 개면 번호를 고르세요.
3. 옵시디언을 완전히 껐다가 다시 켜기.

### Mac

1. zip을 더블클릭해서 풀기.
2. **`install-mac.command`** 를 더블클릭.
   - "확인되지 않은 개발자"라고 막히면 **우클릭 → 열기 → 열기**.
3. 옵시디언을 완전히 껐다가(**Cmd+Q**) 다시 켜기.

### 직접 넣기 (위 방법이 안 될 때)

1. 옵시디언 → 설정 → 커뮤니티 플러그인 → **제한 모드 끄기**.
2. "설치된 플러그인" 옆 📁 아이콘을 눌러 플러그인 폴더를 열기.
3. zip 안의 **`claude-sidebar` 폴더**를 통째로 그 안에 넣기.
4. 새로고침 버튼을 누르고 **Claude Sidebar** 켜기.

## 3. 처음 쓸 때

1. 왼쪽 아이콘 줄의 **🤖**를 누르면 오른쪽에 사이드바가 열려요.
2. 설정 → **Claude Sidebar** 에서 확인할 것:
   - **연결 확인** 버튼 → "연결됨"이 뜨면 OK.
   - **프로젝트 찾을 곳:** 내 코드 폴더가 있는 곳 (쉼표로 여러 개).
     - Windows 기본값: 바탕화면, OneDrive 바탕화면, `문서\GitHub`, `source\repos`
     - Mac 기본값: `~/Desktop`
     - 예: `D:\dev, ~/Documents/GitHub`
   - **자동 비서**를 켜면 아침(08:30)·점심(13:00)·저녁(21:00)에 데일리 노트에 쓰고 알려요. 옵시디언이 꺼져 있어도 돼요. 시각과 점심·저녁 켜고 끄기는 바로 아래에서 바꿔요.

## 4. 사용법

### 물어보기
입력창에 쓰고 **Enter** (줄바꿈은 Shift+Enter). 예:
- "지난주에 적은 회의 내용 중에 할 일만 모아줘"
- "OOO 프로젝트 어디까지 했어? 다음에 뭐 하면 돼?"
- "이 노트 내용으로 발표 목차 짜줘"

입력창 위의 📄 칩은 **지금 열린 노트**예요. 드래그로 선택한 부분이 있으면 그것도 같이 넘어가요. 칩을 누르면 끌 수 있어요.

### 노트 고치기
"이 노트 정리해줘"처럼 고쳐 달라고 하면 **바뀐 줄을 보여 주는 카드**가 떠요. **[적용]**을 눌러야 실제로 바뀌고, 적용한 뒤에도 **되돌리기**가 돼요.

### 브리핑 (아침·점심·저녁)
📅 버튼을 누르면 지금 시각에 맞는 브리핑을 만들어요. 자동 비서를 켜 두면 정한 시각에 알아서 해요.

- **아침 (데일리 노트 맨 위):** 오늘 할 일을 체크박스로 써요.
  - 맨 위: 🔁 오늘 루틴과 📌 오늘 일정
  - 그 아래: Claude가 고른 3~5개 (마감 > 어제 "내일 이어갈 것" > 하던 흐름 > 오래 멈춘 일)
  - 다가오는 일정, 끝난 것 같은 체크 항목, 프로젝트 현황 요약도 함께 써요.
- **점심 (아침 칸 아래):** 오전에 한 것 한 줄 + 오후 할 일 1~3개
- **저녁 (노트 맨 끝):** 오늘 한 것, 루틴 달성(🔁 2/3 · 🔥5일째), 내일 이어갈 것. 다음 날 아침 브리핑이 이어받아요.

### 일정과 루틴
사이드바에 그냥 말하세요. 묻지 않고 바로 넣고, 대화에 뜬 카드의 ↶ 로 뺄 수 있어요.
- **일정:** "금요일 오후 3시 치과", "다음 주 화요일까지 보고서" → `일정.md`
  - 그날 할 일에 📌로 붙고, 시각이 있으면 15분 전에 알림이 와요.
  - 못 하면 다음 날 "밀린 일"로 다시 붙어요.
- **루틴:** "매일 아침 7시 영어 단어", "월수금 헬스" → `루틴.md`
  - 그 요일마다 할 일에 🔁로 붙어요.
  - 체크하면 연속 기록이 쌓이고, `프로젝트/현황.md`에서 이번 주 달성을 볼 수 있어요.
- **직접 고치기:** 노트를 직접 고쳐도 돼요. 루틴을 그만두려면 `루틴.md`에서 그 줄을 지우면 돼요.

### 애플 캘린더 (맥만)
설정 → **애플 캘린더**를 켜요. "Claude 비서 캘린더가 캘린더에 접근하려고 합니다" 창이 뜨면 **허용**을 눌러요(처음 한 번).
- 오늘 캘린더 일정이 할 일 맨 위에 📆로 붙고, 브리핑이 빈 시간을 보고 할 일을 골라요.
- 시각을 말한 일정은 캘린더에 들어가요(15분 전 알림). 어느 캘린더에 넣을지 설정에서 골라요.
- 허용을 안 눌렀거나 잘못 눌렀으면: 시스템 설정 → 개인정보 보호 및 보안 → 캘린더 → **Claude 비서 캘린더** 켜기.

프로젝트마다 `프로젝트/<이름>.md` 노트가 생겨요.
- **할 일 체크리스트:** 처음엔 Claude가 초안을 써요. 체크한 비율이 진행도예요.
- **git 없는 일:** 영어 공부처럼 git이 없는 일도 이 폴더에 노트를 만들고 `## 할 일` 아래 체크리스트를 쓰면 같이 챙겨요.
- **끝난 프로젝트:** 프로퍼티에 `상태: 완료` 를 적으면 브리핑에서 빠져요.

### 자료 정리
- **넣는 법:** 파일을 사이드바에 **끌어다 놓기**, 또는 📥 버튼 → 파일 고르기, 또는 볼트의 `받은자료` 폴더에 넣기 (폴더째 넣으면 그 이름이 분류가 돼요).
- **글이나 링크:** 입력창에 붙여 넣고 📥 누르기.
- **정리 결과:** `자료/<분류>/<제목>.md` 에 요약 노트가 생기고, 원본은 첨부파일 폴더로 옮겨져 노트 안에 들어가요.

## 5. 안심하고 쓰도록

- 대화할 때 Claude는 **읽기만** 해요. 바꾸는 건 [적용] 버튼으로만 돼요.
- git과 GitHub은 **조회 명령만** 돼요. 커밋, 푸시, 삭제 같은 명령은 자동으로 거부돼요.
- 만들거나 바꾸는 곳은 정해져 있어요.
  - `프로젝트/`, `자료/`, `받은자료/` 폴더, `일정.md`, `루틴.md`
  - (애플 캘린더를 켰다면) 사이드바에서 말한 일정만 캘린더에 넣어요. 다른 일정은 읽기만 해요.
  - 데일리 노트의 브리핑 칸 (`%% 비서 … %%` 사이)
  - 볼트 맨 위의 `.rgignore` 파일 하나 (검색이 클라우드 첨부파일에서 멈추지 않게 노트만 검색하도록 함)

## 6. 문제가 생기면

| 증상 | 해결 |
|---|---|
| "Claude Code를 찾지 못했어요" | 설정 → Claude Code 경로에 넣기. Windows는 PowerShell에서 `where.exe claude`, Mac은 `which claude` 결과 |
| "로그인이 필요해요" | 터미널에서 `claude` 를 실행해 로그인 |
| 자동 브리핑·알림이 안 와요 | 기록 확인. Windows: `%APPDATA%\obsidian-claude-assistant\assistant.log`, Mac: `~/Library/Logs/obsidian-claude-assistant.log` |
| 알림이 안 떠요 | Windows: 설정 → 시스템 → 알림에서 Windows PowerShell 알림 켜기. Mac: 시스템 설정 → 알림 → 스크립트 편집기 |
| 사이드바가 안 보여요 | 오른쪽 위의 사이드바 펼치기 버튼, 또는 Ctrl/Cmd+P → "Claude" |

## 7. 지우기

1. 설정에서 **자동 비서 끄기** (자동 실행이 해제돼요).
2. 커뮤니티 플러그인에서 Claude Sidebar를 삭제.
3. (선택) 남은 설정 폴더 지우기. Windows: `%APPDATA%\obsidian-claude-assistant`, Mac: `~/Library/Application Support/obsidian-claude-assistant`
