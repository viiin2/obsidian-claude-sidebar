# Claude Sidebar 사용법: 옵시디언 개인 비서

옵시디언 오른쪽에 붙는 Claude 비서예요. **내 Claude Code 구독**으로 돌아가서 API 키나 추가 요금이 없어요. Windows와 Mac에서 돼요.

| | 하는 일 |
|---|---|
| 💬 물어보기 | 내 노트와 프로젝트(GitHub, 내 PC의 폴더)를 찾아 답하고, 근거 노트를 링크로 달아 줘요 |
| 📅 브리핑 | 아침엔 **오늘 할 일**, 점심엔 **오후 점검**, 저녁엔 **오늘 회고**를 데일리 노트에 쓰고 알림을 띄워요. 옵시디언이 꺼져 있어도 정한 시각에 해요 |
| 📌 일정 · 🔁 루틴 | "금요일 3시 치과", "매일 7시 영어 단어"처럼 말하면 넣어 두고, 그날 할 일에 붙이고, 15분 전에 알려요. 루틴은 연속 기록(🔥)도 세요 |
| 📥 자료 정리 | 파일(PDF, 이미지, 워드, 파워포인트, 한글 hwpx, HTML), 글, 링크, 폴더를 넣으면 요약해서 분류 폴더에 저장해요 |
| ✨ 다듬기 · 💾 저장 | 열린 노트의 맞춤법과 구조를 정리하고(내용은 그대로), 대화를 노트로 남겨요 |
| 📆 애플 캘린더 | (Mac만) 캘린더 일정을 할 일과 브리핑에 쓰고, 말한 일정을 캘린더에 넣어요 |

> **Windows에서 처음 써 보는 버전이에요.** Mac에서는 끝까지 확인했지만 Windows의 설치 프로그램, 자동 실행, 알림은 아직 실제 PC에서 돌려 보지 못했어요. 안 되는 게 있으면 [8. 안 될 때 보내 줄 것](#8-안-될-때-보내-줄-것)을 보고 알려 주세요.

## 1. 준비물

| | Windows | Mac |
|---|---|---|
| **옵시디언** | https://obsidian.md | 같음 |
| **Claude 구독** | Pro 이상 (claude.ai) | 같음 |
| **Claude Code** (필수) | PowerShell에서 `irm https://claude.ai/install.ps1 \| iex` | 터미널에서 `curl -fsSL https://claude.ai/install.sh \| bash` |
| **Git** (Windows 필수) | `winget install --id Git.Git` | 보통 이미 있음 |
| **Node.js** (자동 비서에 필요) | `winget install OpenJS.NodeJS.LTS` | https://nodejs.org |
| **GitHub CLI** (선택) | `winget install --id GitHub.cli` | `brew install gh` |

**Windows에서 PowerShell 여는 법:** 시작 버튼 → `powershell` 입력 → Enter. 위 명령을 한 줄씩 붙여 넣고 Enter.

설치한 뒤에 꼭 할 것:
1. PowerShell(또는 터미널)을 **새로 열고** `claude` 를 입력해 **로그인**해요. 로그인이 끝나면 창을 닫아도 돼요.
2. (선택) GitHub CLI를 깔았다면 `gh auth login` 으로 로그인해요. 그러면 내 GitHub 저장소까지 챙겨요.

## 2. 설치

### Windows

1. zip 파일을 우클릭 → **압축 풀기** → 푼 폴더를 열어요.
2. **`install-windows.bat`** 을 더블클릭해요.
   - "Windows의 PC 보호" 파란 창이 뜨면 **추가 정보 → 실행**.
   - 볼트가 여러 개면 번호를 입력해요.
   - 마지막에 준비물 확인이 나와요. `[!]` 가 있으면 1번의 준비물을 깔아요.
3. 옵시디언을 **완전히 껐다가** 다시 켜요. 작업 표시줄 오른쪽 아래 숨은 아이콘에 옵시디언이 남아 있으면 그것도 종료해요.

### Mac

1. zip을 더블클릭해서 풀어요.
2. **`install-mac.command`** 를 더블클릭해요. "확인되지 않은 개발자"라고 막히면 **우클릭 → 열기 → 열기**.
3. 옵시디언을 **Cmd+Q** 로 껐다가 다시 켜요.

### 직접 넣기 (위 방법이 안 될 때)

1. 옵시디언 → 설정 → 커뮤니티 플러그인 → **제한 모드 끄기**.
2. "설치된 플러그인" 옆 📁 아이콘을 눌러 플러그인 폴더를 열어요.
3. zip 안의 **`claude-sidebar` 폴더**를 통째로 그 안에 넣어요.
4. 새로고침 버튼을 누르고 **Claude Sidebar** 를 켜요.

## 3. 처음 설정 (5분)

1. 왼쪽 아이콘 줄의 **🤖** 를 누르면 오른쪽에 사이드바가 열려요.
2. 설정(⚙️) → 왼쪽 목록 맨 아래 **Claude Sidebar** 에서:
   - **연결 확인** 버튼 → "연결됨"이 뜨면 OK.
   - **프로젝트 찾을 곳:** 내 코드 폴더가 있는 곳. 쉼표로 여러 개.
     - Windows 기본값: 바탕화면, OneDrive 바탕화면, `문서\GitHub`, `source\repos`
     - 예: `D:\dev, ~/Documents/GitHub`
   - **자동 비서** 켜기 → 옵시디언이 꺼져 있어도 아래 시각에 데일리 노트에 쓰고 알려요.
   - **아침 · 점심 · 저녁** 시각 (기본 08:30 · 13:00 · 21:00). 점심·저녁은 끌 수 있어요.
3. 사이드바의 📅 를 한 번 눌러 보세요. 오늘 데일리 노트 맨 위에 오늘 할 일이 생겨요 (처음엔 프로젝트 노트를 만드느라 1~3분 걸려요).

## 4. 매일 쓰는 법

### 물어보기
입력창에 쓰고 **Enter** (줄바꿈은 Shift+Enter).
- "지난주 회의 노트에서 내 할 일만 모아줘"
- "OOO 프로젝트 어디까지 했어? 다음에 뭐 하면 돼?"
- "이 노트 내용으로 발표 목차 짜줘"

입력창 위의 📄 칩은 **지금 열린 노트**예요. 드래그로 선택한 부분이 있으면 그것도 같이 넘어가요. 칩을 누르면 끌 수 있어요.

### 노트 고치기
"이 노트 정리해줘"처럼 고쳐 달라고 하면 **바뀐 줄(+/−)을 보여 주는 카드**가 떠요. **[적용]** 을 눌러야 실제로 바뀌고, 적용한 뒤에도 **되돌리기**가 돼요. ✨ 버튼은 열린 노트를 바로 다듬어요.

### 브리핑 (아침 · 점심 · 저녁)
📅 를 누르면 지금 시각에 맞는 브리핑을 바로 만들어요. 자동 비서를 켜 두면 정한 시각에 알아서 하고 알림을 띄워요.

| 언제 | 데일리 노트에 생기는 것 |
|---|---|
| 아침 (맨 위) | **오늘 할 일** 체크박스: 맨 위에 🔁 오늘 루틴, 📌 오늘 일정, 그 아래 Claude가 고른 3~5개. 다가오는 일정, 끝난 것 같은 항목, 프로젝트 현황 |
| 점심 (아침 칸 아래) | 오전에 한 것 한 줄 + 오후 할 일 1~3개 |
| 저녁 (맨 끝) | 오늘 한 것, 루틴 달성(🔁 2/3 · 🔥5일째), 내일 이어갈 것. 다음 날 아침이 이걸 먼저 챙겨요 |

컴퓨터를 늦게 켜도 몰아서 하지 않아요 (밤에 켜면 저녁 회고만).

### 일정과 루틴: 그냥 말하세요
묻지 않고 바로 넣어요. 대화에 뜬 카드의 ↶ 로 뺄 수 있어요.

| 이렇게 말하면 | 들어가는 곳 | 그다음 |
|---|---|---|
| "금요일 오후 3시 치과", "다음 주 화요일까지 보고서" | `일정.md` | 그날 할 일에 📌로 붙고, 시각이 있으면 15분 전 알림. 못 하면 다음 날 "밀린 일"로 다시 붙어요 |
| "매일 아침 7시 영어 단어", "월수금 헬스" | `루틴.md` | 그 요일마다 할 일에 🔁로 붙어요. 체크하면 연속 기록 🔥, `프로젝트/현황.md` 에 이번 주 달성 |

- 노트를 직접 고쳐도 돼요. 루틴을 그만두려면 `루틴.md` 에서 그 줄을 지우면 돼요.
- 데일리 노트에서 📌 를 체크하면 `일정.md` 도 체크돼요 (반대도 돼요).

### 프로젝트 챙기기
GitHub과 내 PC 폴더에서 **최근 30일 안에 손댄 프로젝트**를 찾아 `프로젝트/<이름>.md` 노트를 만들어요.
- **할 일 체크리스트:** 처음엔 Claude가 초안을 써요. 체크한 비율이 진행도예요.
- **git 없는 일:** 영어 공부처럼 git이 없는 일도 `프로젝트/` 에 노트를 만들고 `## 할 일` 아래 체크리스트를 쓰면 같이 챙겨요.
- **끝난 프로젝트:** 프로퍼티에 `상태: 완료` 를 적으면 브리핑에서 빠져요.

### 자료 정리
- **넣는 법:** 파일을 사이드바에 **끌어다 놓기**, 📥 버튼으로 파일 고르기, 또는 볼트의 `받은자료` 폴더에 넣기 (폴더째 넣으면 그 이름이 분류가 돼요).
- **글이나 링크:** 입력창에 붙여 넣고 📥 를 눌러요.
- **결과:** `자료/<분류>/<제목>.md` 에 요약 노트가 생기고, 원본은 첨부파일 폴더로 옮겨져 노트 안에 들어가요.

### 애플 캘린더 (Mac만)
설정 → **애플 캘린더** 를 켜고, "Claude 비서 캘린더가 캘린더에 접근하려고 합니다" 창이 뜨면 **허용**.
- 오늘 캘린더 일정이 할 일 맨 위에 📆로 붙고, 브리핑이 빈 시간을 보고 할 일을 골라요.
- 시각을 말한 일정은 캘린더에 들어가요 (15분 전 알림). 어느 캘린더에 넣을지 설정에서 골라요.
- Windows에서는 이 설정이 보이지 않아요.

## 5. 사용량과 안전

- **사용량:** 내 Claude 구독 사용량을 써요. 터미널에서 Claude Code를 많이 쓰면 함께 한도에 걸릴 수 있어요. 대화 한 번은 몇 초, 아침 브리핑은 1분쯤 걸려요. 점심·저녁은 짧아요.
- **읽기만:** 대화할 때 Claude는 노트를 **읽기만** 해요. 바꾸는 건 [적용] 버튼으로만 돼요. git과 GitHub도 **조회 명령만** 돼요 (커밋, 푸시, 삭제는 자동으로 거부).
- **비서가 쓰는 곳:** 정해져 있어요.
  - `프로젝트/`, `자료/`, `받은자료/` 폴더, `일정.md`, `루틴.md`
  - 데일리 노트의 브리핑 칸 (`%% 비서 … %%` 사이)
  - 볼트 맨 위의 `.rgignore` 파일 하나 (OneDrive·iCloud에서 안 받은 파일 때문에 검색이 멈추지 않게 노트만 검색)

## 6. 문제가 생기면

| 증상 | 해결 |
|---|---|
| "Claude Code를 찾지 못했어요" | PowerShell에서 `where.exe claude` → 나온 경로를 설정 → **Claude Code 경로** 에 붙여 넣기 (Mac은 `which claude`) |
| "로그인이 필요해요" | PowerShell에서 `claude` 를 실행해 로그인 |
| 답이 안 오고 오류에 bash, git 이야기 | Git이 없거나 다른 곳에 깔림 → `winget install --id Git.Git` 후 옵시디언 다시 켜기 |
| 사이드바가 안 보여요 | 오른쪽 위 사이드바 펼치기 버튼, 또는 Ctrl+P → "Claude" |
| 자동 브리핑이 안 와요 | ① 설정에서 **자동 비서** 가 켜져 있는지 ② 시작 → "작업 스케줄러" → 작업 스케줄러 라이브러리에 `ObsidianClaudeAssistant` 가 있는지 ③ 기록 파일 (아래) |
| 알림이 안 떠요 | 설정 → 시스템 → 알림 → **Windows PowerShell** 알림 켜기, "방해 금지" 끄기 (Mac: 시스템 설정 → 알림 → 스크립트 편집기) |
| 프로젝트가 안 잡혀요 | 설정 → **프로젝트 찾을 곳** 에 코드 폴더 추가. 최근 30일 안에 커밋했거나 고친 git 폴더만 잡아요 |

**기록 파일:** Windows `%APPDATA%\obsidian-claude-assistant\assistant.log` (파일 탐색기 주소창에 붙여 넣기), Mac `~/Library/Logs/obsidian-claude-assistant.log`

## 7. 지우기

1. 설정에서 **자동 비서 끄기** (작업 스케줄러에서도 빠져요).
2. 커뮤니티 플러그인에서 Claude Sidebar 삭제.
3. (선택) 남은 설정 폴더 지우기. Windows `%APPDATA%\obsidian-claude-assistant`, Mac `~/Library/Application Support/obsidian-claude-assistant`

## 8. 안 될 때 보내 줄 것

아래를 만든 사람에게 보내 주면 바로 고칠 수 있어요.
1. **오류 화면 스크린샷** (사이드바의 빨간 글씨, 설치 창 전체)
2. **기록 파일:** `%APPDATA%\obsidian-claude-assistant\assistant.log`
3. **PowerShell에서 아래 결과:**
   ```
   where.exe claude
   where.exe node
   where.exe git
   schtasks /Query /TN ObsidianClaudeAssistant
   ```
4. 언제, 무엇을 눌렀는지 한 줄
